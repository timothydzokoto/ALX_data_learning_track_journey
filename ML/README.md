# Machine Learning — Regression Learnings

Jupyter notebooks covering supervised learning with a focus on regression, regularisation, tree-based models, and ensemble methods.

## Structure

| Folder | Topics |
|---|---|
| `01_Simple_Linear_Regression/` | Intro to SLR, Least Squares, train/test split, model performance |
| `02_Multiple_Linear_Regression/` | MLR with sklearn, advanced analysis, variable selection |
| `03_Regularisation/` | Ridge, LASSO, data scaling |
| `04_Model_Management/` | Saving and restoring models with pickle/joblib |
| `05_Decision_Trees/` | Decision tree theory, sklearn implementation, exercises |
| `06_Ensemble_Methods/` | Bagging, boosting, random forests, heterogeneous ensembles |
| `Code_Challenges/` | End-of-topic challenges and MCQ assessments |

## Tools & Libraries

- Python 3
- scikit-learn
- pandas, NumPy
- Matplotlib, Seaborn
