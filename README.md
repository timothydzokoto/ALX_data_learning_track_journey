# ALX Data Learning Journey

Full-stack data science learning repository covering Python fundamentals, machine learning, NLP/classification, and data visualisation.

## Structure

| Folder | Description |
|---|---|
| `Python_Track/` | Python basics through advanced topics — OOP, algorithms, pandas, statistics |
| `ML/` | Regression, regularisation, decision trees, and ensemble methods |
| `NLP/` | Text processing, classification models, SVMs, neural networks |
| `PowerBI/` | Data visualisation and dashboarding with Power BI |

## Tools & Libraries

- Python 3, Jupyter Notebooks
- scikit-learn, pandas, NumPy, Matplotlib, Seaborn
- Power BI
