# Python Track

Notebooks covering Python from fundamentals to data science applications.

## Structure

| Folder | Topics |
|---|---|
| `01_Python_Basics/` | Variables, data types, strings, casting, print formatting |
| `02_Control_Flow/` | Loops, conditionals |
| `03_Functions/` | Functions, lambda, recursion |
| `04_Data_Structures/` | Lists, tuples, sets, dictionaries |
| `05_OOP/` | Classes, OOP principles |
| `06_Algorithms/` | Sorting, searching, time complexity |
| `07_NumPy_and_Pandas/` | NumPy arrays, DataFrames, string manipulation, regex |
| `08_Visualisation/` | Matplotlib, Seaborn, interactive plots |
| `09_Statistics/` | Probability, distributions, hypothesis testing |
| `10_Clean_Code/` | PEP-8, debugging, error handling |
| `11_Python_Packages/` | Building and distributing Python packages |
| `Integrated_Projects/` | P1 (Farm management), P2 (EDA), P3 (Data validation) |
| `Code_Challenges/` | GCC submissions and timed challenges |
| `Exams/` | Exam notebooks and datasets |
