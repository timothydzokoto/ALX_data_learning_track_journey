# NLP and Classification

Notebooks covering natural language processing and supervised classification.

## Structure

| Folder | Topics |
|---|---|
| `01_Text_Processing/` | NLP basics, text cleaning, feature extraction (TF-IDF, BoW) |
| `02_Binary_Classification/` | Logistic regression, classification metrics, model improvement |
| `03_Multiclass_and_Tree_Models/` | Multiclass classification, tree-based classifiers |
| `04_SVM_KNN_NaiveBayes/` | Support Vector Machines, KNN, Naive Bayes |
| `05_Model_Tuning_and_Neural_Networks/` | Hyperparameter tuning, neural network classifiers |
| `Code_Challenges/` | MCQ assessments, code challenges, hyperparameter tuning challenges |
| `Projects/` | Titanic survival classification project |
